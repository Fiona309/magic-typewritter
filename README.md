# Stranger Things · Alphabet AR

《怪奇物语》Will 字母灯 AR 输入法：食指指向墙上的字母，捏合输入，像 Will 一样用灯泡向现实世界传话。

## 技术栈（纯前端，无构建）
- **MediaPipe Hand Landmarker**（双手模式）—— 指向 / 捏合 / 👍 / ✊ / 🙌 五种手势
- **DOM + CSS** —— 字母光晕、灯光闪烁、句子放大动画（无 Three.js）
- **WebAudio** —— 全部实时合成音效（咔哒+电流、铃声、氛围重音），按 M 静音

## 运行
```bash
cd alphabet-ar
python3 serve.py 8643    # 禁缓存开发服务器
```
桌面版 Chrome/Edge 打开 http://localhost:8643

## 手势
| 手势 | 动作 |
|---|---|
| ☝️ 食指指向 | Hover 字母（灯泡高亮，带迟滞防抖） |
| 🤏 捏合 | 输入当前字母 |
| 👍 竖大拇指 | 空格（结束单词） |
| ✊ 握拳 1 秒 | 删除上一个字母（按住连删） |
| 🙌 双手举起 | 整句完成：句子居中放大 + 全屋灯亮（#31 图）+ 闪烁 3 次 |

## 与 PRD v2.0 的差异（经用户确认）
- 背景 = 暗客厅图（room-dark.png），摄像头为右上角预览窗，非摄像头全屏 AR
- 空格手势 OK → 👍（OK 与捏合动作太接近，误触率高）
- 新增删除手势 ✊（PRD 缺失）
- 不使用 MediaPipe Pose（双手举起用 Hands 即可判断）；不使用 Next.js（单页 demo 无构建收益）
- 音效全部 WebAudio 合成，无 mp3 文件

## 调试
- 调试默认开启：右上角手部关键点 + 左下角 HUD + 字母判定圈（`?nodebug` 或按 `D` 关闭）
- `?mouse=1` 鼠标模式：移动=指向，点击=输入，空格键/退格/回车对应三种手势
- `?auto=1` 自动演示：循环输入 "HI MOM"
- 字母坐标、手势阈值全部在 `js/config.js`
